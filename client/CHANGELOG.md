# Changelog

## 0.2.0

First VS Code release — full port of the scc_inspector Notepad++ plugin.

- Real-time SCC diagnostics (parity, timestamps, buffer overflow, never-displayed/never-erased captions, non-monotonic timecodes)
- Hover tooltips with decoded commands, packet-accurate timing, and caption buffer state
- Decoded-caption code lenses with in/out timecode
- Outline / breadcrumb navigation of caption blocks
- Red line tint and minimap band decorations on problem lines
- Syntax highlighting for timestamps, control codes, and caption text
- Frame rate auto-detection (23.98 / 25 / 29.97 DF / 29.97 NDF) with override setting
